# Ананасики Mini App v0.1

Черновой запуск Telegram Mini App для заработка "ананасиков".

## Экономика
- 30 🍍 = 1 ₽
- В версии 0.1 доступен 1 источник дохода: просмотр рекламы.
- За один просмотр рекламы начисляется +3 🍍.

## Что уже реализовано
- UI mini app под мобильный формат.
- Интеграция с Telegram WebApp SDK (`ready`, `expand`).
- Локальное хранение баланса и истории действий в `localStorage`.
- Кулдаун рекламы (15 сек между просмотром).

## Локальный запуск
```bash
python3 -m http.server 4173
```

Открыть в браузере: `http://localhost:4173`.
